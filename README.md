# Alexandre Ribas Sousa — CV website

Static, responsive CV website prepared for GitHub Pages. It includes English and Portuguese content, a light/dark theme switch, publication links and a downloadable copy of the CV.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files to its root, including `AS CV.pdf` and `perfil AS.jpg`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing these files (usually `main`) and choose the `/(root)` folder.
4. Save. GitHub will show the published address in the Pages section after deployment.

For a personal address such as `username.github.io`, name the repository `username.github.io`. For a project address, keep a repository name such as `cv_alex`; the site will be published under `https://username.github.io/cv_alex/`.

The portrait and downloadable PDF link point to `perfil AS.jpg` and `AS CV.pdf` in the repository root. Keep both files beside `index.html` when publishing.
